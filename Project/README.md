> Pair programming 

Pair programming is an excellent way to practice coding in a team setting, a skill that is highly valued in the software development industry.

During the event, you will be randomly assigned a pair member. One of you will take on the role of the "driver," responsible for writing code, while the other will be the "navigator," tasked with reviewing the code and providing guidance. This dynamic duo approach will help you learn from one another and improve your problem-solving abilities.

Here's [more info](./pair.md)
