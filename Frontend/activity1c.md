### IronNutrition

- **Step 1** :Follow the instructions provided in the [IronNutrition] lab and solve the task using the `useState()` hook. 
- **Step 2** : Refactor your code to employ the `useReducer()` hook in place of `useState()`.

### Setup 

Create a new React application. Please choose only **one** alternatives

- First method

Open your terminal and run:
```sh
npx degit tx00-web/react-starter#main useReducer-lab
cd useReducer-lab
npm install
```

- Second method using CRA
Open your terminal and run:

```sh
npx create-react-app useReducer-lab
cd useReducer-lab
npm install
```

- Third method using Vite
Open your terminal and run:
```sh
npx degit tx00-web/vite-template#main useReducer-lab
cd useReducer-lab
npm install
```
