# Grading Criteria: 

> Please **be aware** that failing to submit the reflection journal will result in **no grading** for the assignment.

### Max grade for Week4:

- Web Development
  - In-Class Activities:  40/300 points
  - Individual homework: 40/300 points **The grade for the individual homework is based on what you write in the reflection journal. I take your word for it!**
- Project Course: 
  - In-Class Activities: 45/350 points
  - Reflection Journal: 20/150 points

### Max grade for Week 1, 2 and 3: 

  - 135/350 points: In-Class Activities for project course
  - 60/150 points: Reflection Journal
  - 120/300  points: In-Class Activities for Web course
  - 120/300 points: Individual homework 

### Grade will be determined based on the following components:

- Project Course (5 cr)
  - In-Class Activities (35%)
  - Reflection Journal (15%)
  - Separate Feedback at the end of the course (5%)
  - Group Project (45%)
- Web Development (10 cr)
  - In-Class Activities (30%)
  - Individual homework (30%)
  - Separate Feedback at the end of the course (5%)
  - Exam (35%)
