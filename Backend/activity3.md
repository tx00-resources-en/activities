# Activity 3

This activity is an **OPTIONAL** homework. It is meant for **those who want to have more practice**

### Phone Book API: 

Develop an API for managing contacts in a phone book. Users can perform CRUD (Create, Read, Update, Delete) operations on their contacts, including:

- Create Contacts: Users can add new contacts to their phone book, including details like name, phone number, email, address, and additional notes.

- Retrieve Contacts: Users can fetch their contact list, either as a whole or by searching for specific contacts using filters like name, phone number, or category.

- Update Contacts: Users can edit and update contact information, such as updating phone numbers or adding more details.

- Delete Contacts: Users can delete contacts they no longer need.


### Task Management API: 

Create an API for managing tasks, to-do lists, or projects. Users can create, update, and delete tasks, set deadlines, and mark tasks as completed. The API can provide filtering and sorting options for tasks.
